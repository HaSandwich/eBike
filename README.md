## eBike
This is half of a bigger project to eventually build a fully autonomous bike. For now, this is essentially just the drivetrain, built to let the bike move around on its own while still being usable as a normal rideable e-bike when needed.

This project at the core connects a BLDC motor through a large reduction to the rear wheel of my bike making it go around 20 mph using 3d printed parts and regular metric hardware.

> **Current status:** Mechanical side of the drivetrain in complete and a human can control the speed of the rear wheel using a manual input throttle. Now working of the steering and the balancing through mini projects like an inverted pendulum.
---

## build overview

The entire ebike conversion has 3 main parts: Frame Clamp, Motor Mount, and the rear pulley

all of this comes together to securely mount everything to the bike and run everything.

- 3D printed in PLA

- 12 : 180 pulley ratio

- 1450-5M-15 Timing Belt

- Turnigy Aerodrive SK3 - 6374-149KV Brushless Outrunner Motor

- Flipsky 75100 Pro V2.0 VESC
